# Security Fundamentals Assessment

## SWYNEX Technologies – Internship Task 1

### About the Project
This repository contains my Security Fundamentals Assessment completed as part of the SWYNEX Technologies internship Task 1.

The assessment was conducted using authorized, intentionally vulnerable labs from **PortSwigger Web Security Academy** to understand common web application vulnerabilities.

### Objectives
- Identify common web application security vulnerabilities.
- Understand how these vulnerabilities can be exploited in a controlled training environment.
- Document security findings and evidence.
- Recommend suitable mitigation strategies.

### Tools and Platforms
- PortSwigger Web Security Academy
- Burp Suite Community Edition
- Web Browser

### Labs Completed

| No. | Lab Name | Vulnerability |
|---|---|---|
| 1 | 2FA Simple Bypass | Authentication |
| 2 | Unprotected Admin Functionality | Broken Access Control |
| 3 | File Path Traversal – Simple Case | Path Traversal |

### Key Learnings
- Importance of server-side authentication and two-factor verification.
- Importance of proper access control for administrative functionality.
- Risks of accepting unvalidated file paths from user input.
- Using Burp Suite to inspect HTTP requests and responses.
- Documenting vulnerabilities and recommending security improvements.
